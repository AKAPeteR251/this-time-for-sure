## UI 实现约定

沿用 uGUI、TextMeshPro，逻辑画布 1920×1080，使用 Canvas Scaler 与锚点适配。检查 1280×720 和 16:10；不要直接把整张截图作为功能 UI。背景、角色、卡框、图标、文字与按钮分别搭建。按钮面板可使用九宫格图片，文字由 TMP 渲染。

角色卡面维持 2:3，使用保持比例或遮罩裁切，不拉伸立绘。结果页固定五列两行，脸和手尽量不被标签覆盖。召唤页核心按钮固定右下，详情页给立绘留出足够空间。结果和重复角色标签均由已经计算的抽卡数据驱动，跳过演出不重新抽取。

建议色板：背景 #101827 / #192538，正文 #F2E9D8，金色 #CBA76B，冰蓝强调 #86CDF0。R 蓝、SR 紫、SSR 金、UR 黑金用于视觉层级；具体角色稀有度仍由正式数据决定。

画面里的“星界回响”、资源数量、职业名、稀有度和日期均是布局示例，不冻结游戏名称、卡池、概率或实际数据。元素用于角色视觉区分，不扩展战斗系统。视差开关仅为参考；分层素材未就绪时默认关闭或隐藏。

## 涉及的 Unity 概念与调参

Canvas Scaler 控制不同分辨率下的 UI 比例；RectTransform 锚点保持导航与核心按钮位置；Grid Layout Group 控制十连卡片行列；Image 的 Preserve Aspect 和 Mask 保证立绘比例；TMP 控制字重、字号与换行。先调卡片间距、右侧信息栏宽度和底部按钮安全区，再调金色装饰与光效强度。
