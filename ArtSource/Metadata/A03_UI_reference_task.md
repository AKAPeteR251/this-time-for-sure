整屏生成图作为布局与视觉参考，不能作为一张图片覆盖可点击 UI。UI 开发需要分开构建 Image、TMP/Text、Button、CardView、背景、角色图和特效。固定核心按钮位置，CanvasScaler 参考尺寸 1920×1080，实测 1280×720 与 16:10。

图内文案、角色名与示例数量是演示数据；由开发读取真实模型。未实现的保底、共鸣或版本收藏不能根据参考图自动当作已实现功能。
