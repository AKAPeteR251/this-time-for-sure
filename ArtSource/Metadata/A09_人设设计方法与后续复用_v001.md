# A09-DESIGN-RECAP：人设设计方法与后续复用

日期：2026-10-11。依据：用户本聊天的风格、属性、稀有度要求，C14/C15/C16、R003 的 03 稿锚定、A09 实际输出及绫音修订。任务仅总结与冻结后续工作方式，不启动生成、不改 Unity 或共享人设配置。

## 一、这次采用的设计方向

题材采用传统日式幻想 RPG 职业：法师、牧师、精灵弓箭手、战士、巫女、魔法少女，以及盾卫、吟游诗人、弩手和歌姬。职业是读懂人物的第一入口，元素提供配色和纹样，性格决定表情与手势，稀有度决定设计的复杂度和姿态张力。

画法沿用户认可的清楚线稿、赛璐璐平涂、明确阴影边界和克制材质高光。皮肤、布料、丝袜不做油亮大渐变；金属可以有少量清楚的边缘亮面，但不能把全身画成写实反光材质。眼神、嘴角和面部可读性优先于细碎花纹。

本批人物均为成年女性。年轻感通过脸形、活力、表情和姿态体现，成熟感通过眼神、身形与行动气质体现。不同年龄气质不等于复制一张脸再换头发。人物吸引力来自职业辨识、反差性格、亲近感、姿态和衣装的共同设计。

外层《这次一定出》与内层《星界回响》继续分开；角色源图不烘焙游戏名、姓名、等级、稀有度或界面文字。

## 二、先定人，再定衣服

每个角色先回答五项：她做什么、是什么性格、如何对待玩家/队友、用什么动作表达、最容易记住的两个视觉符号是什么。

| 设计层 | 必须明确的内容 | 在画面中的落点 |
|---|---|---|
| 稳定身份 | ID、名字、成年年龄、已有脸/发色/眼色 | 保留身份，不因换工具重新设计 |
| 职业职责 | 肉盾、战士、射手、法师或辅助 | 主道具与全身轮廓，先于饰物 |
| 性格反差 | 一个主要性格与一个可见反差 | 眼神、嘴角、手势和朝向 |
| 六元素 | 冰、火、风、雷、光、暗之一 | 可读衣料色块＋简洁道具纹样 |
| 稀有度 | R/SR/SSR/UR | 细节数量、轮廓张力、服装层次 |
| 服装结构 | 主衣装、露肤重点、袜/鞋、材料 | 每件衣物如何连接和穿着 |
| 姿态 | 稳定站姿、转身、步进或轻悬浮 | 保持重心与道具握持可信 |

一个角色只设一两个最强视觉重点。先选“盾与护甲”“长弓与精灵耳”“宽袖与御币”等清楚组合，再添加属性纹样。背景故事和台词可以指导表情，但不要期待一张图表现全部设定。

## 三、稀有度分级

| 等级 | 设计重点 | 服装与姿态 | 需要避免 |
|---|---|---|---|
| R | 实用、朴素、职业清楚 | 少饰物、清楚大色块，站姿或轻动作 | 高级王冠、宝石堆叠、复杂蕾丝、强行镂空 |
| SR | 职业和性格更鲜明 | 特有袖型、披肩、法器，轻快转身或步进 | 每人都变成同一套短裙黑丝 |
| SSR | 收藏感、识别度和轮廓 | 更精致的衣装层次与道具，明显动态或从容悬浮 | 细节淹没脸，职业道具退化成装饰 |
| UR | 张扬、力量感与第一眼记忆 | 强斜线、发丝/披风呼应动作，集中而精致的重点 | 只加金色、只加露肤、堆满大光效 |

R 的朴素与高稀有度的华丽形成反差，可服务游戏对抽卡审美的讽刺；R 仍要有完整构图、清楚五官和正常制作质量。稀有度不靠裸体程度区分。露肩、腰侧小开口、侧开衩等按具体职业选择，不作为人人必填项。

R 风格锚图明确为 [米洛本地 03 稿](../Characters/R003/source/R003_candidate_03_v001.png)，不是后来的 04 稿。继承其清楚线稿、克制材质和实用服设，不复制其脸、盾甲或站姿。

## 四、六元素配色方法

| 属性 | 代表色 | 辅助色 | 常用符号 |
|---|---|---|---|
| 冰 | 冰青蓝 #86DCE8 | 深冰蓝 #3F7094、霜白 #EFFBFF | 雪晶、六角、尖锐冰面 |
| 火 | 朱红 #E7634A | 炭红 #81382D、暖白 #FFE7C7 | 火舌、斜纹、剑柄火纹 |
| 风 | 翠绿 #63BF91 | 深绿 #32664F、浅薄荷 #DCF2E3 | 叶片、流线、飘带 |
| 雷 | 紫罗兰 #B191EF | 深紫 #60458C、电白 #F1EBFF | 折线、菱形、几何电纹 |
| 光 | 暖象牙金 #F0DFA8 | 浅金 #C6A15D、暖白 #FFF4D0 | 太阳、短芒、暖白灯芯 |
| 暗 | 深靛紫 #575074 | 深夜色 #292839、灰紫 #B4A1C6 | 月弧、蚀环、深色内衬 |

色值是方向，不要求生成图逐像素等于 HEX。至少用一块缩小后仍能看见的衣料/披肩/腰带色块，搭配一处简洁职业道具标记。只有一个很小的彩色宝石通常不足以表现属性。

保留人物本来的发色和职业主色。例如绫音保留红白巫女服，用紫色袖衬、腰带和雷纹表明雷属性；浅汐保留海蓝剑士身份，用绿披带表现风；露弥娅保留粉发白粉裙，以象牙白披带和暖白星杖表达光。

雷与暗通过明度和纹样区分：雷偏明亮紫色与折线，暗偏低明度靛紫与月弧。火与光通过衣料和道具区分：火偏朱红，光偏暖白象牙色。星、月、灯火、海潮只是视觉主题，不新增元素或伤害类别。

属性色属于人物设计，稀有度框、漏光与徽记属于界面/演出。不得用金色卡框替代光属性设计，也不把大量元素光环、烟雾和粒子烘焙在人物 PNG 上。

## 五、职业轮廓与动作

| 职业 | 最强识别点 | 动作倾向 | 结构检查 |
|---|---|---|---|
| 肉盾 | 厚盾、胸肩甲、护臂 | 稳定承重、盾在保护方向、脸露出 | 盾握把与手臂连接，防护量感 |
| 战士 | 轻甲、剑、明确进攻方向 | 前步、肩髋对转、发丝/披风顺势 | 握剑、剑尖、重心和脚掌 |
| 射手 | 弓/弩、护腕、箭具 | 轻便转身或稳定持弩 | 弓弦连续、弓尖完整、指握合理 |
| 法师 | 杖/御币等法器、明确职业服 | 施法手势、轻悬浮或仪式步进 | 法器完整，手势不遮脸 |
| 辅助 | 日轮杖、琴、镜与铃 | 安抚伸手、抱琴、从容转身 | 乐器握持、法器与手明确连接 |

动作不是每人都抬腿。可以有稳定站姿、微侧身、步进、转身、屈膝和悬浮；通过职业与性格选择。全身、发梢、裙摆、鞋和道具必须完整，画面留边不等于衣物已经补全。

### 绫音最新袜鞋设定

用户已通过 [SR003 v002](../Characters/SR003/Internal_A09_v002/SR003_character_v002.png) 的视觉验收。取消黑色长丝袜；改为略高于脚踝、至小腿下段且不超过小腿的白色棉质足袋，平直闭合袜口，无 V 字开口。仍穿简洁红带、深色薄底的平底草履。脚部不加金饰、蝴蝶结、铃铛或流苏。

## 七、本次流程错误与后续必经步骤

**本次错误：A09 在用户要求继续生成时，沿内置透明路线直接生产了后续十人，没有先为每个新增人设用本地 Anima 出样张并询问用户是否满意。** 已有职业参考稿或通用风格认可，不能代替这次新服装、属性、脸与姿态的逐角色人设确认。内置透明工具获得许可，也不能推导为可以跳过人设确认。

后续新角色按以下顺序执行：

1. 建立带任务 ID 的单角色人设卡，注明哪些身份已有参考、哪些是新提案。核对职业、成年年龄、元素、稀有度与轮廓重点。
2. 确认本地 ComfyUI 服务、Anima 模型、节点和选定 LoRA 的实际能力。读取已运行工作流和参数，不把旧链存在当成本轮已经运行。
3. 使用本地 Anima 先出最多三张独立人设样张，保留实际正负提示词、seed、API/UI 工作流、prompt_id、history 和源 PNG。样张可以是 RGB 单色背景，不能称作透明成品。
4. 展示样张并明确询问用户人设是否满意、选择哪张，重点比较脸/发型、职业道具、服装、属性色与姿态。**取得该角色确认前，不继续正式透明生产。** 可以继续归档、检查等不依赖确认的工作。等待超时不等于确认。
5. 按意见用本地链修改样张并再次确认；若工具不可用或画风不合适，如实说明，只有用户明确同意后才能变更样张工具。不得默默绕过本地环节。
6. 用已确认样张作身份参考，按已获授权的正式链重建/精修并制作透明层。若用内置 image_gen，必须保住脸、发型、衣装、道具、配色与选定姿态；两种工具的来源分别记录。
7. 检查完整性、真实 alpha、黑白灰边缘、脸/手/握持、头像焦点；交付立绘、头像、缩略、参数、源稿和限制，再请求正式素材视觉验收。

这项确认要求来自用户本次纠正，是人设生产中的必要选型环节；不扩大为文件整理、导出或其他常规工作都要重复审批。现有已验收人物不为补流程记录而重跑，不编造事后确认或补造历史本地样张。

### 本地链复用注意

米洛平涂 03 稿的真实工作流见 [API](../Workflows/A07_R003_candidate_03_api.json)、[运行记录](A07_R003_candidate_03_run.json)、[history](A07_R003_candidate_03_history.json)。主模型沿 Anima Turbo；新 Detailer/Reina 的 model 0.6、CLIP 0 来自用户当时的选择。复用前以该 API 的实际连接/强度为准，不把后续 04 稿提高 Flatline 的试验混写进 03 锚图参数。

```text

性格与反差：主性格一句，反差一句。
表情与手势：具体到眼神、嘴角、手的动作。
两个最强视觉重点：
主衣装 / 露肤位置 / 袜与鞋：
属性色块位置 / 简洁纹样：
姿态与重心 / 道具握持：
稀有度细节上限 / 禁止项：
本地候选编号 / 用户选定编号与意见：未确认时明确写待确认。

```

### 本地 Anima 候选提示结构

```text
One original adult female fantasy RPG character, [age], full body.
Clean thin anime linework, restrained flat colors, hard-edged cel shadows,
matte skin and cloth, minimal controlled metal highlights.
[Distinct face, hair, eyes, personality expressed through expression.]
[Profession, one main prop, rarity-appropriate simple/refined clothing.]
[Element-colored cloth area and one simple motif; specific socks and shoes.]
[Balanced pose, correct hand grip, full hair, weapon and footwear.]
Portrait 2:3, generous outer margin, plain neutral gray background.
No scenery, ground shadow, particles, text, logo, card border or UI.
```

负向沿真实工作流记录，关注油亮写实质感、肢体错误、道具断裂、裁切、伪文字和背景；不要把细节限制写成一长串互相矛盾的要求。本地 RGB 样稿不填“真实透明”来冒充 alpha。

### 正式透明重建提示结构

```text
Input image is the USER-APPROVED IDENTITY reference for this character.
Preserve face, hair, expression, outfit, element colors, chosen pose and prop.
Rebuild one complete transparent character sprite with clean cel shading.
Complete only missing extremities, include all hair, cloth, shoes and weapon.
Genuine alpha background with 5-8% outer margin.
No floor, shadow, separate effects, text, UI, border or redesign.
```

局部修改明确“只改什么、保留什么”。用户只改袜鞋时，不顺便修改脸、衣装、武器或属性。保存修改前原稿和新版本；生成式编辑有漂移可能，必须目视比较，不承诺像素级一致。

## 九、交付与验收口径

规格沿项目：立绘 1024×1536 RGBA，缩略 256×384，头像 256×256；保持完整画布与比例，每人单独记录头像裁切和左下原点面部 UV。源稿、选中样张、工作流/提示词、实际参数、alpha 检查和哈希能追溯。

不得以画面棋盘格或单色背景宣称透明，不把普通缩放叫正式重建，不把外扩画布叫补画裁切，不把 SAM 分割分数叫视觉验收。工具未披露的模型版本/seed/CFG 写未披露。原稿、旧版本、ID 与资产 GUID 保留。

本地样张通过人设确认、正式素材通过视觉验收、Unity 导入/演出运行验收是三种不同证据。美术通过不自动证明角色已接入游戏；总览也不是 Unity 运行截图。

涉及 Unity 概念：Sprite、RGBA、Alpha Is Transparency、RectTransform、Preserve Aspect、头像裁切与稳定 ID。调参先看脸和职业轮廓，再看属性色块与动作，最后调边距、头像和独立特效；稀有度/属性演出在各自层上调整，不修改人物来烘焙 UI。
