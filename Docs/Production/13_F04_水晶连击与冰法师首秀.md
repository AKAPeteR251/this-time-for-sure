## 1. 体验与完整流程

**点击抽卡 → 手写或跳过补签 → 一次签约提交 → 巨印与契约升空 → 巨环中的水晶特写 → 连续点击蓄能，裂纹扩展与稀有度漏光 → 剧烈震动与破裂 → 全屏白光 → 角色近景缩回完整立绘 → 稀有度徽记与名字逐字浮现 → 自由停留/确认。**

水晶像被玩家亲手唤醒的封印。每一下都要有声音、形变/短震和光的即时回应；越密集越快达到爆发。破裂后的白光直接接人物，避免在此后另叠一段长视频。参考用户描述的由大到小特写节奏，构图、徽记和文案原创。

十连共用一次契约/水晶，之后按原批次逐张展示，每张仍等待确认。最后一张显示“查看结果”。不为每张角色重新敲水晶。

## 2. 高频点击的推进规则

采用0—1的演出蓄能值，未点击不自行增加。建议起点：每次新按下增加约0.065；连续输入间隔短于0.28秒时，获得最高约1.5倍的视觉蓄能加成。实际通常约11—16次点击完成，最终用手感调参，不把点击次数写成硬规则或展示计数。不同速度可以得到不同的总点击次数和完成时长。

鼠标在水晶区域按下、Space/Enter的新按下等效。按住不自动连续触发。蓄能阶段允许在上一下短震/裂纹显露期间继续点击；不要继续沿用旧三阶段的动画锁，使高频点击被吞掉。同一个物理输入只计一次，不能由按钮与全屏监听各累计一次。

进度保留，不倒退、不要求限时完成。停手约0.25秒后点击引起的剧烈震动逐渐平息，仅保留轻浮动和低强度漏光，等待下一次输入；不能停手后自己破裂。达到阈值后只进入一次终结动画。

| 蓄能区间 | 画面 | 每次点击反馈 |
|---|---|---|
| 0—0.20 | 完整晶体，大型星环缓慢转动 | 晶核短亮、清脆敲击，约2—3px短震 |
| 0.20—0.45 | 短裂纹出现并扩展 | 边缘少量碎光、较低的裂纹声 |
| 0.45—0.75 | 深裂纹、晶壳张开，稀有度光从缝中泄出 | 漏光脉冲、约4—7px震动、蓄力音增强 |
| 0.75—1.00 | 强漏光、晶核回吸与不稳定震动 | 水晶本体约8—12px短震，背景仅短促轻震 |
| 达到1.00 | 极短收束后播放碎片飞散 | 重击/破裂音，强光迅速覆盖场景 |

数字均是1280×720参考画面的制作起点，按Canvas尺度适配。水晶可以震得明显，操作按钮保持稳定。全屏白光用于最终一次爆发，连击只在水晶和裂缝周围闪动。

v004完整/短裂纹/深裂纹是三个**视觉素材档位**，不是三个输入阶段。用蓄能值选档，并用交叉显露、独立漏光、冲击、震动连续推进；不把一次点击直接映射为换一张状态图。已有24帧破裂可先试24—32fps，依据片段调整。

## 3. 稀有度光与角色主题

| 稀有度 | 漏光主色建议 | 识别方式 |
|---|---|---|
| R | 冰蓝 `#75C9FF` | 单层细光，短促清亮 |
| SR | 紫 `#B784FF` | 双层光晕和聚拢碎光 |
| SSR | 金 `#FFD36E` | 金色裂缝、清楚光束与冲击 |
| UR | 金红 `#FFAE55` / `#FF6854`，白色晶核 | 多层金红脉冲、短收束后更强爆发 |

单抽使用已计算角色的稀有度；十连水晶使用该批最高稀有度，仅给出等级信号，不提前展示角色身份。随后每张的徽记与光效读取自己的稀有度。连击速度只推动演出，不改变Draw、稀有度、NEW或收藏。

冰法师是 SSR：**水晶漏光和稀有度徽记为金色，人物背景/冰晶细节为冰蓝**，两种信息分层。破裂顶点可以白光统一收束，但白光前必须看得出稀有度颜色。

v004现有发光已合成在部分图片中，不能假设给所有RGBA直接乘Tint就能准确变成四档色。SSR先使用可用金色层；执行者实测其它色，若发光底色影响明显，由A06补中性白发光层/掩码，保留晶体壳与碎片的材质。无需为四档重建四套场景。

## 4. 冰法师登场：白光中的近景缩回完整立绘

角色：既有 `SSR001`，名字“冰法师”，称号“冰城守望者”。使用 `Assets/_Game/Art/Characters/UIIceMage/UIIceMage_character_v001.png`。本轮实际核对1024×1536、RGBA、存在561001个完全透明像素、meta已存在；不把它声称为可独立摆动头发/衣物的多层人物。

| 从最终破裂起计 | 画面与信息 |
|---|---|
| 0.00—0.20秒 | 水晶飞散、短冲击，全屏白光到峰值；角落跳过仍可见可点 |
| 0.20—0.55秒 | 白光消退，冰法师脸部与上半身近景从光中出现；约1.8—2.0倍立绘，焦点锁在脸部 |
| 0.40—1.15秒 | 顺滑缩回1.0倍完整构图，背景反向轻推进形成空间感；人物比例保持，面部不被光遮住 |
| 0.65—0.90秒 | 原创SSR金色徽记在信息区短亮、回落到稳定尺寸 |
| 0.85—1.30秒 | “冰”→“法”→“师”逐字浮现，字间约0.11—0.14秒 |
| 1.25—1.65秒 | 称号出现，NEW随后单独出现；脸部和名字附近强光收束 |
| 约2.0—2.3秒后 | 完整角色与信息稳定，进入自由停留，等待新的确认输入 |

脸部焦点和近景偏移由Inspector参数指定，通过实际画面确定，不能只放大围绕脚底/画布中心的Image而将脸移出画面。近景允许身体裁切，最终完整立绘必须落入安全区。保持一张透明立绘与背景分开变换即可，首轮不制作Live2D。

名字使用真实UI字体：预留完整名字的宽度，每字从低透明度/微弱上浮进入，约0.15—0.20秒稳定。新增字符时前面的字不能横向跳动。可以配极轻的笔锋/亮音，不用机械打字声；称号、NEW与名字分别显示。具体用现有uGUI实现，不以全面换TMP为前置。

建议人物在中央偏右，徽记/名字/称号在左下高于进度的位置；沿用右上跳过、左下i/10、右下下一张/查看结果。实际1280×720、1920×1080、1600×1000检查，文字不得遮脸或侵占按钮。保持U03可消费的节点或交接精确改动。

角色动画中的新点击只完成当前张，包括把名字补到完整状态；下一个新的确认才前进。水晶爆发期间的高频输入不积攒到角色阶段，不自动跳过名字或连翻。

## 5. 原创稀有度特殊徽记

徽记代表稀有度，不把冰法师雪花直接当SSR标志。共用“星界契约”的星芒与环纹语言，靠轮廓和结构区分，不只换色；R/SR/SSR/UR文字由Unity渲染，不烘焙中文、角色名或品牌。

| 档位 | 原创轮廓 | 展示节奏 |
|---|---|---|
| R | 四芒星、开放单环、银蓝细边 | 直接短亮 |
| SR | 六芒星、双侧短翼、紫色双弧 | 两段聚光 |
| SSR | 八芒星、双环、左右展开的几何桂翼、金色棱面 | 环纹展开、徽记短闪后稳定 |
| UR | 十二芒星、冠状上弧、分离外环、金红内核 | 外环重组、内核脉冲、短光冠 |

先做SSR徽记并放冰法师实际构图看清轮廓，再产同系列其它三档。首轮程序可用uGUI几何轮廓实现SSR；正式美术包由A06产，不让徽记素材等待阻塞水晶功能样例。最终48/96/192像素显示均应可辨；装饰避开徽记中心。

## 6. 旁白与声音的互动调度

定稿三句不改。前两句随巨印、升空与巨环入场播放；水晶等待只留低强度环境声，不重复长旁白。蓄能满触发最后一句“星门，为您而开！”，结尾落点配破裂/白光峰值。若现有音轨较长，可在终结短收束中开始最后一句，并以实际音源尾部重音调破裂时刻，不把整句硬塞进0.2秒。

现有 `ArtSource/Audio/P04/voice_fitted_0.wav` 至 `voice_fitted_2.wav` 已存在，可重新导入成分段音轨；当前 `SummonAudio.BeginCeremony` 仍整体调度，P05需改为阶段触发。点击声可分层增强，不能高频叠得刺耳或把旁白淹没。跳过停止旁白/环境/蓄力/破裂并清除白幕。
