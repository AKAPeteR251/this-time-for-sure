## 导入与验收步骤

1. 在已有 Unity 停止 Play，执行 `Assets → Refresh`，等编译完成。
2. 执行 `Tools → 这次一定出 → 程序 → 初始化并校验开发基线`。
3. 查看生成的 `Docs/Production/Verification/P00_editor_status.json`：应为正确 Unity/包版本、`missingFolders` 为空、`labHasOnePrototype`、`repeatedSetupPreservedLab` 和 `repeatedSetupPreservedBuildScenes` 均为 true。工具自身连续初始化两次，并比较实验场景文件与构建列表。
4. 执行 `Tools → 这次一定出 → 程序 → 打开程序实验场景`，按 Play。界面由现有 PrototypeGame 创建，确认一个 Canvas、一个 EventSystem，以及占位卡牌。
5. 单抽 → 结果 → 详情 → 返回；十连 → 跳过 → 十张结果；查看收藏，免费补充。初始资源 30，单抽加十连后应为 19，补充后 29。
6. 停止 Play 后再打开实验场景，确认不重复创建启动对象。以上实测完成才可标已验收。
