美术当前无需扩画十二人或重生成整套页面。若 UI 实测发现边缘光晕、小图标或按钮状态影响使用，再建立单项返修 ID；四态对齐应统一可见主体位置，而不仅是统一画布。下一批正式角色、手/道具修复、其他透明人物层，在 F02 试玩后确定优先级。
