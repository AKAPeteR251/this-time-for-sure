# F10-CARD-UI — 角色卡面分层素材清单 v001

依据：用户要求按 `ArtSource/UI/CardConcept/card_sr_thunder_reference_v001.png` 拆解素材并列清单。状态：待美术制作、待视觉验收，未修改游戏运行卡面。

## 统一方向

2:3竖卡，薄金属/晶体边框，角色为主体；NEW和稀有度收进卡框，取消倾斜红贴纸和大黑方块；底部名字区柔和渐隐，元素图标置左。参考图用于风格和层级，不要求重画角色或逐像素复刻装饰。

四档共用尺寸、内窗、标签位置与名字区：R冰蓝、SR紫、SSR金、UR炫彩。SSR金色、UR炫彩沿用既有揭示页的方向，降低小卡装饰密度，保持文字识别。

|雷电、月亮、飘散粒子|本轮属于角色内窗画面，不追加通用雷电特效或所有角色的背景重制。|

## 母版排版与安全区

母版1024×1536，以下以左上为原点，矩形写作(左,上,右,下)。这是建议布局，美术可微调，但需将最终精确值写入layout.json，四档必须一致。

|区域|建议像素矩形|要求|
|---|---|---|
|卡框内窗|(24,32,1000,1512)|尽量给角色完整空间，中央主体区域不被框挡住。|
|NEW标签|(72,64,392,184)|横向整齐放在框内，不倾斜、不超出卡面；留足字形空间。|
|稀有度徽记|(768,56,984,272)|右上角小型标识；R/SR/SSR/UR统一贴图矩形，调整内部字形大小适应3字母。|
|名字区|(24,1272,1000,1516)|上部渐隐，名字落在下部清晰处，不用不透明直切黑条。|
|元素图标|(72,1336,224,1488)|原图独立摆放，不画进名字底。|
|名字文字|(264,1352,920,1472)|以角色名为主，兼容2—6个汉字；安全边距不能被装饰压住。|
|脸部建议安全区|(170,280,854,900)|通过现有角色画的裁切/定位让脸与眼睛清楚；不要强行拉伸角色。|

角饰不要侵入名字文字区或脸部；SSR/UR可以更精致，但不扩大内窗遮挡。主框不做九宫格拉伸，按2:3整体等比显示。
