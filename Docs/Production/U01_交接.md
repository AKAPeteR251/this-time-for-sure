Unity 工程内均位于 `Assets/_Game/`：

| 文件 | 用途 |
|---|---|
| Scripts/UI/PrototypeGame.cs | 页面组件、布局、事件绑定、揭晓、UI 复验协程 |

## 打开与复验

1. 在 Unity 中停止 Play，等待脚本导入。
2. `Tools → 这次一定出 → UI → 打开独立UI原型`，按 Play。
3. 默认 `Use Fixed Mock` 勾选，左上标为 UI MOCK。结果按已有角色表顺序返回，不做随机概率验证。
4. 检查单抽 → 跳过 → 点击结果卡 → 隐藏 → 恢复 → 返回 → 十连 → 收藏 → 再抽。免费补充固定 +10。
5. `Tools → 这次一定出 → UI → 验证交互与三种窗口` 执行实际 Button 事件、资源与页面断言，使用 GameView 固定尺寸截图；结束后退出 Play，恢复此前 GameView 尺寸选择。
6. 要接原有内存随机，停止 Play 后取消根对象 `Use Fixed Mock`。通过 Main 体验时该字段默认关闭。

复验输出在工作区 `Docs/Production/U01_Verification/`。`Compile.ps1` 使用现有 Unity 安装的 Roslyn 和工程生成的引用列表，输出到此目录，不写 Library；它是源码编译检查，不代替 Play。

## Unity 学习点与调参

- RectTransform 的锚点决定页面区域；CanvasScaler 以 1920×1080 为基准适配窗口，Match=0.5。
- AspectRatioFitter 负责在卡格内保持 2:3，Image.preserveAspect 保持立绘比例。
- Button.onClick 发出请求；Coroutine 只播放已经计算的结果；CanvasGroup 隐藏侧栏时同时关闭交互与射线。
- 修改 `UI/Styles/PrototypeUITheme.asset` 调颜色；Inspector 修改三档 Reveal Seconds 调速度；Portraits 接图。独立场景的 Prefab 引用主题，不需重建页面逻辑。
