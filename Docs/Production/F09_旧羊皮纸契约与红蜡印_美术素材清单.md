# F09-CONTRACT 旧羊皮纸契约与红蜡印

状态：用户已明确风格需求；本文件为美术制作清单，未生成或接入新素材。

## 画面方向

召唤契约改为写实的陈旧羊皮纸：暖米黄/浅褐底，真实纤维与皮质肌理，边缘自然磨损、少量浅污渍和细小裂口，带轻微折痕及褶皱。主体依然平整，保留签字和阅读的空间，不做大面积烧焦、血迹或严重破损。

英文契约采用手写艺术字：标题有优雅花体，正文像蘸水笔/羽毛笔写出的深褐墨迹，略有深浅变化；可辨认、拼写准确，不用乱码充当古文字。写实度统一，避免纸是照片、蜡印是卡通图标。

蜡印为深红/酒红色真实封蜡，有厚度、不规则圆形边缘、自然蜡液堆积、压印浮雕、克制高光与细微裂纹。徽记为原创星门/星形几何压印，不照搬现实家族纹章或现有游戏Logo。印面无文字，优先保证缩小后图形清楚。

## 英文排版建议稿

以下为本轮原创英文文案建议，给美术制作时使用准确文本；不涉及旁白改为英文，现有神圣宣告仍保留。

品牌小字：

```text
Star Echo
```

标题：

```text
Covenant of the Stars
```

正文：

```text
By this name, I awaken the echoes
that slumber among the stars.

Let this covenant be sealed,
with the stars as witness.
```

签名提示如需要加入英文文字层，仅写：

```text
Sign your name
```

标题可以较华丽；正文控制花饰，让游戏画面缩小到1280×720仍能读。文字必须逐字核对，优先用实际字体排版或人工修正生成字形，不以生成图的看似英文为验收依据。提供使用的字体文件（可交付时）、字体名称与实际许可文件/来源；无法交付字体则交可编辑文字/矢量层和说明。无需为生成准确字形新增工具或购买字体。

## 排版与动态内容留白

当前签署页/升空契约是横版偏4:3区域，因此母版先做横版4:3；后续程序保持等比，不让写实纹理拉伸。不要把透视拍摄角度烘焙进去。

以画布左上角为(0,0)，以下百分比为构图建议，正式预览需标出最终边界：

- 上部约8%—28%：品牌与契约标题。
- 中部约30%—55%：英文正文，避开重折痕。
- 下部约60%—83%：主签名留白，左侧10%至约72%；纸纹与褶皱在此区更淡，方便深色实时墨迹与成立后的金线显示。
- 右下约76%—94%：蜡印贴纸位置，印记不压标题、正文和主签名；预览可展示此位置，但独立空白纸仍无蜡印。
- 不烘焙“返回/跳过”按钮、开发提示、任何中文/英文玩家名字或外层游戏名《这次一定出》。玩家用户名由游戏实时填写，中文名仍需保留可用字体回退。

纸边磨损与褶皱集中在外围，纸中央保留真实纤维但不过度噪杂。整体仍有神圣、郑重的契约感，而不是恐怖游戏残页。
