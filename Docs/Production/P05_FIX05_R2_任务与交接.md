## 运行、接口与调参

打开工程的 Main 并 Play 即生效，无需再次重建 UIPrototype。Editor 菜单内 P05Fix05R2Setup 的准备/验证入口，或写 `P05_FIX05_R2_Verification/Fix05R2.request` 为 `prepare` / `verify`；准备只更新它明确管理的引用，运行验证会进出 Play 并产出报告。

`FastRevealView.Begin/Animate/Finish/Transition`、`PrototypeGame.AdvancePresentation/HandleEscape`、只读批次与 RevealIndex 沿用。旧 `confirmCardButton`、`revealCount` 私有对象已移除；外部 UI 不应再查找它们。输入仍走 AdvanceSurface 的 RevealPointerGate；下一张事件不得由动画完成自动触发。

在 `P05FeelConfig.asset` Inspector 替换 `revealSsrBadge` / `revealNewPlaque` / `iceMageBackdrop`，调 `iceBackdropAlpha`（当前 0.22）、`faceZoom`（沿用 1.9）、`faceTarget`（本轮 0.55,0.68）。布局锚点在 FastRevealView：人物 .26,.10—.81,.96，雪花 .22,.07—.82,.95，未来奖励 .80,.26—.97,.67。名字出现进度 .30—.48，稀有度 .67—.83，NEW .84—.95；这些是本张动画归一化进度。

涉及 Unity 概念：RectTransform 锚点保证窗口比例变化；Image.preserveAspect 保持素材比例；Sprite alpha 与 Image.color.a 控制雪花淡显；GraphicRaycaster 与 pointer gate 防止同次点击穿透；ScriptableObject 保存调参及可替换素材引用。运行时生成 UI，所以只改 Hierarchy 中 Play 的临时对象不会永久保存。
