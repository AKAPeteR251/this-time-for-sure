## 目标与范围

替换水晶互动阶段的星空舞台，做成封闭的地下召唤圣殿：低矮厚重的圆形穹顶、深蓝黑石材、古金镶边、中央圆形祭坛、两侧暖色火盆。水晶的冰蓝光与火盆的琥珀光形成冷暖对比。保持二次元游戏风格，石材有层次但不要堆满写实污渍和细碎雕刻。

只制作室内环境。现有 F07 水晶、三个立环、底环和漂浮碎片继续复用；图中的新水晶与环仅是构图参考，不需要重做。契约、前奏和逐张角色结果仍沿用原流程；已通过的角色结果星云背景保留。

## 必做模型

| 资产/建议节点名 | 制作内容 | 拆分与复用要求 |
|---|---|---|
| `Altar_Base` / `Altar_Steps` | 中央低矮圆形祭坛、2—3层宽而浅的台阶 | 台面、台阶独立；中央留给现有水晶机构，不加新水晶底座 |
| `Altar_Inlay` | 台面与外围地面的金色几何镶边、仪式纹样 | 独立网格或遮罩；分普通金属与发光部分，发光可单独控制 |
| `Floor_Module` | 深色石砖地面、通向祭坛的前景地面 | 可重复模块，减少接缝；有微弱反光，不做镜面水池 |
| `Wall_Module` / `Wall_Alcove` | 环形室内墙面、少量凹龛 | 普通墙与凹龛分别做模块；后墙必须完整，不能露出星空 |
| `Pillar_Module` | 两侧厚重石柱，少量古金装饰 | 一套可重复；柱身与装饰可分材质，不必每柱不同 |
| `Ceiling_Dome` / `Ceiling_Ribs` | 封闭圆穹顶、同心石质梁肋 | 穹顶与梁肋分开；有厚度，室内侧法线正确，不能靠背面消失 |
| `Brazier_Base` / `Brazier_Bowl` | 左右主火盆及少量远处小火盆 | 一套复用；金属盆、石座独立，火焰交Unity播放 |
| `Wall_Emblem` | 凹龛中的古金几何仪式挂饰 | 一款复用即可，不画字、不加游戏名 |

优先保证固定正面游戏镜头可见部分的质量，不需要扩展成可探索大地图。用现有F07水晶机构做尺寸和构图参照，交一版已摆好的完整房间，再保留可独立编辑的模块。

## 必做材质与特效贴图

| 素材 | 建议规格 | 要求 |
|---|---|---|
| 石材、古金属材质 | 主要纹理2048；小装饰1024即可 | BaseColor、Normal、金属度、粗糙度；可选AO。标注通道和颜色空间。粗糙度由程序转URP平滑度，不预设未知打包方式 |
| 祭坛发光纹样遮罩 | 2048 PNG，灰度或透明 | 纹样清楚，背景无颜色；不烘焙光晕、灯光和镜头效果 |
| 火焰翻页图 | 4×4或8×8图集，总图2048 PNG RGBA | 透明背景、循环连续；提交帧数、顺序、建议帧率；偏柔和琥珀色，火芯浅黄，不带盆与背景 |
| 低处薄雾/尘埃纹理 | 512—1024 PNG RGBA | 中性灰白，透明背景，无固定场景光照；用来铺少量贴地薄雾和室内尘埃 |

蓝色水晶光、暖色点光、光晕、雾的运动与祭坛发光节奏在Unity里控制，不烘焙到墙面贴图。现有素材若满足这些要求可复用，清单中标出路径即可。

## 可选项，首版不等待

- 少量布幡、角落装饰：作为点缀，不能遮住水晶和三环。
- 火盆烟气、几粒火星：可由Unity粒子实现，不必做成整段视频。
- 灯光遮罩或光束纹理：按后续实机效果补充。

不做整幅房间背景视频、不新增角色/徽章/配音，不把此包扩大为水晶裂纹投射光束或最终破裂效果制作。

## Blender与Unity交付

建议交付：`D:/vibe/这次一定出/ArtSource/Scenes/F08/F08_UndergroundAltar_v001.zip`。

包内包含：

```text

```

- 模型：真实3D几何，不能把参考图贴在一块平面上充当房间。默认1 Blender单位=1米；按现有F07实际机构尺寸摆放，manifest写出房间/祭坛尺寸和缩放，不擅自更改F07原件。
- 节点：环境根节点 `F08_UndergroundAltar`；祭坛中心在地面原点，地面为零高度，根节点缩放1。导出采用Unity兼容轴向转换并记录设置；交付后以Unity导入结果核对，不靠反复旋转补偿。
- Pivot：祭坛中心、柱/墙模块底部、火盆底部；保留合理父子层级与可重复模块，不合成一个不可编辑网格。
- `.blend` 保留原始可编辑物体与材质；FBX不依赖未应用的几何节点/修改器。不要仅交Blender灯光、程序材质或合成器效果，外观需有可用贴图或可说明的简单材质。
- 材质区域至少区分石材、古金、祭坛发光纹样。提供UV，重复石材可平铺；需要烘焙灯光的静态环境提供不重叠的第二套UV或注明待Unity生成。
- 完整房间FBX即可首版接入，不强制每个模块另导FBX；节点必须能独立选择/开关。
- 参考灯光与相机保留在Blender便于复现；截图包含正面16:9游戏构图及侧视结构图。最终灯光、相机和运动由Unity重新配置。
- `manifest.md` 记录模型/纹理清单、节点名、材质名、尺寸、轴向、贴图通道、火焰图集参数、缺项及来源。无需提交Unity `.meta`，导入后由Editor生成。

## 构图验收点

1. 正面16:9视角能看出穹顶、后墙和祭坛，有明确封闭室内空间。
2. 水晶与三个环周围有空隙；环旋转到不同倾角时不撞石柱、穹顶或墙面，不被火盆遮挡。
3. 墙面较暗但可读，水晶机构最醒目；火盆是暖色陪衬，薄雾不能遮住中心。
4. 不直接照抄图中水晶尺寸；围绕现有F07机构配房间，另交较近的水晶互动构图预览，防止远景水晶过小。
