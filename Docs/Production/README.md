## 总指挥的工作方式

本聊天承担总指挥：拆任务、冻结共享约定、核对策划、审核交付、维护任务板。**用户于 2026-10-08 明确本聊天只负责验收和计划**；当前不执行游戏实现，主场景集成交程序 agent 按任务单完成。美术、程序、UI 各有明确的文件归属。需要跨归属修改时，在交接单说明具体 diff 或交接范围。

F02/F03已交付，F04水晶当前版本已由用户验收。旧13/14保留施工与接口依据，当前按15讨论战斗循环、按16讨论角色命名与人设；16覆盖15旧职业建议。战斗的新增范围以用户2026-10-11要求为准，旧原型“不扩战斗”不继续作为禁令；装备/联网/付费等仍不扩展。C06是接入前快照，不把旧无.meta/空绑定继续算作当前缺项。

初次交付准备了派工材料，随后本聊天亲自实现 F01；未创建其他聊天或启动执行 agent。本聊天不会在结束后自动监控其他聊天；后续进度由继续对话或明确安排的运行来推进。
