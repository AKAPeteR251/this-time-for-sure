## 下一小批建议：P05-CRYSTAL

建议优先把已经交付的 v004 素材做成可玩的互动，然后转入收藏与外层内容。此处是讨论方案，尚未启动执行任务。

建议流程：

**签名/补签 → 一次签约提交 → 巨印与契约升空 → 巨环中的水晶特写 → 三次主动点击 → 破裂与星门爆开 → 原批次逐张确认 → 总览。**

| 时点 | 画面与操作 | 声音 |
|---|---|---|
| 签约至水晶出现 | 复用现有盖印、升空和巨环；转入完整水晶特写 | 播前两句定稿旁白，落到稳定环境底音 |
| 等待第一次点击 | 完整水晶轻微浮动，等待不限时 | 底音保持，不循环整段旁白 |
| 第一次点击 | 切换短裂纹、轻震 | 第一档裂纹声 |
| 第二次点击 | 裂纹加深、漏光与更明显震动 | 第二档裂纹声，能量增强 |
| 第三次点击 | 播放破裂序列，衔接星门与光幕 | 触发“星门，为您而开！”；将爆点重新对齐该句落点 |
| 第一张角色出现 | 强光退到人物后，沿用现有逐张等待接口 | 接四档揭晓音，角色停留安静清楚 |

这里不把原来的6.8秒当作含等待的总时长。自动动画可以保持短促，三处等待由玩家决定。现有完整旁白不能跨等待点一直播放；先按原始三句音源拆分/调度，再依据实际试听决定是否换声线。

交互建议：每次新的点击只推进一阶段；短震/切换时不积攒点击；破裂和光幕中的点击不穿透为第一张角色确认。签署跳过仍只补签，签约后的右上跳过/Esc仍直接展示同批结果并停止声音。Space/Enter建议与阶段点击等效。

输入目标和角落按钮沿用 U03 安全区。可用轻微呼吸亮光和简短“点击水晶”表达操作，不展示开发步骤或长说明。进度 i/10 在角色阶段显示，水晶阶段不提前泄露角色身份。

拟由程序执行 agent 负责 Presentation、音频调度和必要的 `PrototypeGame` 阶段接口、Main 集成；UI agent 仅在需要时补水晶命中区与提示；美术 agent 只补接入后确认缺少的层。签约提交与 Draw、概率、收藏计数保持现有行为。

本小批交付应包含：真实 Main 的三次点击片段、每次等待可停留的输入记录、各阶段跳过/清音、第一张和末张确认、三窗口安全区。指定批次与随机批次分别说明，不新增完整规则或故障测试体系。

涉及 Unity 概念：Sprite 状态切换、透明序列帧、协程与输入阶段、AudioSource 分段播放、RectTransform 震动。调参入口：水晶大小、浮动幅度、各次震动、切换时长、漏光强度、破裂帧率和旁白爆点。
