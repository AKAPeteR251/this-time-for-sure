## 实测与视觉检查

- 重新读取 A04 manifest 的 36 项 Unity 目标文件：全部存在、assetId 无重复，实际尺寸与清单一致，SHA256 全部一致。
- 23 项新素材含真实 alpha；四张卡框中心 alpha 都是 0。背景为 RGB，六职业完整图与缩略图为 RGB，不能当作人物分层。
- 本地查看素材接触表、六职业接触表、背景与人物合成 QA、透明冰法师和三页参考图。角色的线稿、阴影语言和元素配色可支持同一原型；深蓝背景、象牙白/黄铜控件与冰法师能形成统一页面。
- 单独的冰法师为 1024×1536 整人物透明层，适合主页和详情，未拆头发/身体/服装。现有六职业完整图不具备同画布的可运动人物层和补洞背景。
- 原型可以容忍现有道具/手部和弓剑裁切缺陷；巫女符札仍有伪文字，冰法师靴部与法杖下段交叠需正式稿细检。正式母版阶段再精修，当前不退回重做整批。
- 四档卡框画布/内窗并不一致：R/SR 为 528×736，SSR 为 528×832，UR 为 527×832。不能套同一遮罩或按卡框外画布拉伸人物；人物保持 2:3，每档单独校准。
- 按钮四态都是 832×336，但 alpha>32 的可见边界分别为 normal `(26,99,805,299)`、selected `(25,93,806,295)`、pressed `(26,73,806,273)`、disabled `(26,73,807,274)`（左、上、右、下像素）。可见内容垂直相差最多约 26 像素，**四态直接 SpriteSwap 暂不通过**。首版用固定底图加 Color Tint；需要四态时先对齐可见主体，保留新版本。
- 图标的小尺寸清晰度、人物边缘光晕、按钮九宫格与文字对比要在实际窗口检查。交接中的 Border 数字只是起点，不能作为已验证设置。

## Unity 学习点与调参

Sprite 导入负责图片引用和 `.meta`；Image/Mask 决定实际卡窗；CanvasScaler 决定不同窗口布局；Color Tint 可先提供按钮状态反馈。调参顺序为人物大小与锚点 → 卡窗 → 按钮高度/Border → 图标大小 → 光效强度，先保持可点、可读、比例正确。
