# F06-ART-REVEAL-BURST（可选升级）

P16双段炸裂已用现有素材和Shader接入Main，以下不阻塞程序交付。若要增加外圈碎片轮廓、替换目前的单一冰屑，可交美术生成。参考用户两张抽卡爆发截图的放射方向和层次，自行设计原创元素，不截取原游戏素材。

| 文件 | 尺寸 | 内容 |
|---|---|---|
| reveal_burst_shard_A_v001.png | 512×1024 | 尖长的不规则薄片，尖端向上，灰白或浅蓝可调色 |
| reveal_burst_shard_B_v001.png | 512×1024 | 较宽的破碎菱片，非对称锯齿边，尖端向上 |
| reveal_burst_shard_C_v001.png | 512×1024 | 弯曲、稍分叉的细长碎片，尖端向上，与A/B形状明显不同 |
| reveal_burst_streak_v001.png | 256×1024 | 单束放射光尾，亮端朝上、尾部渐细柔化，灰白可调色 |

统一要求：真实RGBA透明背景，单元素，四边alpha为0，安全留白约8%；不要文字/角色/Logo/整圈构图，不含硬矩形或棋盘底。外圈碎片需有清晰形状、可见明暗面，避免全部生成细线。光尾不烘焙到碎片里，程序分别控制运动、亮度和淡出。

交付 `ArtSource/Effects/F06/RevealBurst/` 下独立PNG、manifest.md（尺寸/透明/方向/来源）、保留原始生成稿。程序正式导入Unity时由Editor产生.meta，不手填GUID。当前内圈打光由Shader生成，暂不需要美术做整张打光背景。
